# E-ticaret Kampanya ve Dönüşüm Hunisi Analizi

## Proje Hakkında
Bu projede BigQuery ve SQL kullanarak online kampanya performansını ve Google Analytics 4 verileri üzerinden e-ticaret ziyaretçilerinin dönüşüm hunisini analiz edeceğim.

## Proje Hedefleri
- Online kampanyaların performansını incelemek.
- E-ticaret ziyaretçilerinin dönüşüm hunisini analiz etmek.
- BigQuery üzerinde SQL sorguları yazma ve açıklama deneyimi kazanmak.

## Kullanılan Araçlar
- Google BigQuery
- SQL
- Google Analytics 4

## Proje Durumu
Devam ediyor.

## Klasör Yapısı
- `sql/` — Projede kullanılan SQL sorguları ve notlar.
